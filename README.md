# Sudoku Studio

**A thoughtful Sudoku experience for a clearer, calmer solve.**

Sudoku Studio brings the classic 9×9 puzzle to a clean, responsive game designed for focused play. Choose a challenge, work through the grid at your own pace, and use helpful tools when you need them.

## The experience

- **A fresh puzzle every time** — generated Sudoku boards with a unique solution.
- **Four difficulty levels** — Easy, Medium, Hard, and Expert.
- **Stay in control** — track your time, mistakes, hints, and score as you play.
- **Useful solving tools** — add pencil notes, undo a move, or reveal a hint.
- **Pick up where you left off** — your current game can be continued on the same device.
- **Play your way** — use a keyboard, mouse, or touch controls on desktop and mobile.
- **Learn as you go** — an interactive tutorial introduces the rules and game controls.
- **English and Spanish** — the interface follows your browser's preferred language.

## How to play

Fill every empty cell with a number from **1 to 9**. Each number must appear exactly once in every row, column, and 3×3 box. The starting numbers are fixed; use deduction to complete the rest of the board.

## Built with

HTML, CSS, and JavaScript — with no framework required to play.

# Sudoku Studio

**Una experiencia de Sudoku para resolver con claridad y calma.**

Sudoku Studio lleva el clásico rompecabezas de 9×9 a una experiencia limpia y adaptable, pensada para que te concentres en cada jugada. Elige un desafío, avanza a tu ritmo y usa las herramientas disponibles cuando las necesites.

## La experiencia

- **Un tablero nuevo en cada partida** — Sudokus generados con una única solución.
- **Cuatro niveles de dificultad** — Fácil, Medio, Difícil y Experto.
- **Mantén el control** — consulta el tiempo, los errores, las pistas y la puntuación.
- **Herramientas útiles** — añade notas, deshaz una jugada o revela una pista.
- **Continúa cuando quieras** — puedes retomar tu partida en el mismo dispositivo.
- **Juega a tu manera** — usa el teclado, el ratón o los controles táctiles en escritorio y móvil.
- **Aprende mientras juegas** — un tutorial interactivo explica las reglas y los controles.
- **Español e inglés** — la interfaz sigue el idioma preferido del navegador.

## Cómo jugar

Completa cada casilla vacía con un número del **1 al 9**. Cada número debe aparecer exactamente una vez en cada fila, columna y bloque de 3×3. Los números iniciales no se pueden cambiar; usa la lógica para completar el tablero.

## Tecnologías

HTML, CSS y JavaScript — sin necesidad de un framework para jugar.
